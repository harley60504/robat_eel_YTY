# Outputs Layout

This folder is organized by output type.

- `datasets/free_swim/`: free-swim CSV measurements.
- `datasets/rectangle_course/`: rectangle-course path-following CSV measurements.
- `datasets/sweeps/`: parameter sweeps and lambda/frequency comparison CSVs.
- `datasets/tethered/`: tethered force CSV measurements.
- `datasets/turning/`: turning and bias-test CSV measurements.
- `experiments/hopf_tuning/`: Hopf tuning result folders with best-parameter JSONs and sweep CSVs.
- `models/`: trained PPO/model zip artifacts.
- `presentations/`: generated presentation decks and related build files.
- `real_video_analysis/`: extracted images and quick analysis from real robot videos.
- `reports/`: generated documents, spreadsheets, paper notes, and plots.
